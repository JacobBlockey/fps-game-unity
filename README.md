# FPS Game - Unity Project

This project is an upcoming First-Person Shooter (FPS) game built in the Unity Engine.

## Getting Started
To get started with this project, follow these steps:
1. Install [Unity Hub](https://unity.com/download) and the latest LTS version of Unity.
2. Clone this repository to your local machine.
3. Open the project folder using Unity Hub.

## Features (Planned)
- Player movement and mechanics
- Weapon system
- AI enemies
- Dynamic environment
- Multiplayer support (optional)
